## 二、节奏批评（按天）

### Day1（10/23）：六题全开 + 工程全家桶，火力太散

时间线（git 可查）：11:57 六题五段式拆解 → 12:14 联网核实四家企业 → 12:24 spec-kit SDD/TDD/issue/worktree 四件套 → 12:40 本地 issue/PR 流程 → 12:51 题 05 重写 → 13:53 六篇讲解稿+网页+视频。同一天下午：尽调废案 7 份（15:05–16:10）→ ppt 废案（16:27–17:22）。

三条批评：

1. **选题前六题全开合理，但每题做到「讲解视频」级过深。** 竞拍只需要 3 分钟 pitch + 一页纸，视频是终局才该投的产能。用 100% 深度做 1/6 概率的事，期望收益算不过账。
2. **口径没拍板就开写终稿。** 尽调废案写到「尽调报告」才发现方向错，ppt 废案 276 个文件全扔——这是 Day1 最贵的两笔学费，病因都是「先写后想」。
3. **72 小时演示战里搬进整条生产线。** spec-kit/TDD/worktree/闸本身没错，但两天半吃不到它的收益（tests/ 里测的其实是 demo HTML，不是产品代码）。过程资产的投入上限应该是「能把 Day3 的演示撑起来」。

### Day2（10/24）：五条模型线并行，没有止损线

glm / kimi / minimax / deepseek v1+v2 / solar v1+v2 / c5 / prd_c5……同一天开出至少 5 个模型/方案战场，fail_demo×2 + 原型废案共 260+ 文件是这一天的尸体，活下来一版 sunwin.html。

批评：**多模型试错本身是 FDE 的正确战术**（假数据比没数据好、快速试错），缺的是时间盒 + 拍板人。每条线 30–45 分钟出可演示骨架，到点不开会直接砍。没有拍板人 → 每条线做到半山腰 → 每条都舍不得扔 → 全扔。

### Day3（10/25）：展示层补课 + 调研倒挂 + leader 缺席

booth/海报/口播/领英案例集中在这一天；同时 customer_analysis 调研也是这天做的（自我批评报告自述「首轮只做了 1 次官网抓取 + 2 次搜索」，实测官网存量仅 9 条 vs 题面假设 200 条，差 20 倍）。

三条批评：

1. **调研倒挂。** 客户调研是 Day1 第一象限的事，干在最后一天 → 发现（渠道根本没接上、存量只有 9 条）来不及回灌方案，只能「标注待确认」。
2. **幸存的翻盘点：** 红线清单 + 自我批评 + 页面标注模拟数据——把诚实边界立住了。在没接真实数据的比赛里，这是败部最值钱的翻盘点。
3. **leader 缺席 → 无头苍蝇。** 根因不是缺个 dictactor，是「拍板权 + 信息枢纽」跟着人走、没有制度化。人一走，方向、分工、节奏三样同时消失。

## 三、OPC/FDE 视角的知识经验（我的版本，待与评委视角对表）

1. **终局可见性过滤器。** 每个产出先问一句：「终局那天评委/客户会看到它吗？」看不到的降级成一句话备忘。讲解视频×6、尽调 7 份、工程闸，都不在终局可见清单上。
2. **调研 → 拍板 → 原型 → 叙事，四步不许倒挂。** Day1 前 4 小时只干三件事：吃透题面、盘点存量、拍板一个 idea。「200 条假设 vs 9 条实测」就是倒挂的代价。
3. **时间盒止损代替 leader 喊停。** 并行试错合法，但每条线 30–45 分钟，到点必拍板。OPC 没有人帮你喊停，就用闹钟当 leader。
4. **机制入库，排泄物不入库。** booth_1 的 build.py + TTS + 词级时间戳 + 模板对齐是全场最值钱的机制资产；122 个 caption-probe log 是排泄物。判定标准只有一条：**能缩短下一次交付时间的才入库。**
5. **诚实边界是模拟战的得分点。** 页面右上标「模拟数据」、红线清单把「运营成本降 30%」钉死为无依据（还标出「部署成本降 30%」是信息安全部署成本的误用陷阱）——评委怕的不是假数据，是假话。
6. **一个人的五顶帽子要有切换仪式。** Leader 五角色（统一方向/明确分工/导演拍板/同步信息/把握里程碑）在 OPC 身上是自己一个人戴。解法是把 leader 的存在感外包给三张纸：① decision log（今天拍了什么板、为什么）② 里程碑表（Day1/2/3 必须交付什么）③ 单一事实源（口径只写一处）。换帽子先写三行：目标 / 交付 / 止损。

## 四、对团队反思的回应

- **你的岗位不是配角。** PPT + booth + 演讲 + 盯计时器 = 展示导演，这是终局评委唯一看得见的岗位，是最后一公里。
- **缺的不是强人，是拍板机制。** 你自己给 leader 的定义（不是 dictactor，是把思想收成共识、把人放对格子）靠找不靠等；找不到时用机制补：决策记录 + 里程碑倒排 + 单一事实源。
- **草台班子 → 专业的最短路径是终局倒排。** 从「Day3 评委看什么」往回推 Day2/Day1 该干什么，把分工钉死在倒排表上。有了倒排表，谁缺席都知道该干嘛——凝聚力靠制度，不靠人治。

---

## 五、结论（就选这三件套）

下次组队 / 独立作战，骨架就用：**终局倒排 + 时间盒止损 + 机制入库**。不用配新工具——仓库里的 build.py 出片流水线、红线清单模板、decision log 三样就能落地。若要长期复用，booth 出片流水线值得沉淀成一个可安装的 skill（改词→TTS→字幕→出片→验证一键跑通）。
