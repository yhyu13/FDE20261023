# overview · FDE 训练营三天复盘（2026-10-28）

## 干了什么
对 GPS 2026 FDE 训练营（10/23–25，北美十四校二组 · 题 02 申沃）三天产出做全量体检：盘点 assets/（day1023/24/25、customer_analysis）+ 根目录五个废案包 + git 提交时间线，批评工作节奏，并从一人公司 FDE 视角总结知识经验，回应团队领导力反思。

## 关键结论
- **产出三七开**：真金 = sunwin 原型 + booth 展位套件（kiosk 自循环 + TTS + build.py 出片流水线）+ 客户调研五件套（含红线清单）+ 海报；垃圾 = 五个废案 zip（ppt 废案 276 文件/447MB、尽调废案 28 万字、fail_demo 多模型全灭等）+ 122 个视频流水线 log + 19,786 个 vendor node_modules + 双份手工副本。
- **节奏三病**：①Day1 六题全开且每题做到视频级 + 口径未拍板就开写终稿（两轮大废案）+ 演示战里搬生产线；②Day2 多模型并行无止损线；③Day3 调研倒挂（客户调研最后一天才做）+ leader 缺席暴露拍板权未制度化。
- **OPC 经验六条**：终局可见性过滤器 / 调研→拍板→原型→叙事不倒挂 / 时间盒止损 / 机制入库排泄物不入库 / 诚实边界是得分点 / 五顶帽子用 decision log+里程碑+单一事实源托管。
- **团队反思回应**：展示导演是最后一公里非配角；缺的是拍板机制不是强人；草台班子专业化走终局倒排。
