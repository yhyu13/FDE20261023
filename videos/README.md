# 讲解视频 · 六道真题

> 一句话：六条片子，每条约 3–4 分钟，**讲的是同一份场景数据**——
> `problems/NN-*-讲解稿.md` 同时是路演念稿、网页版和视频脚本。
> 改稿子要**重跑整条链**（配音 → 时间轴 → 渲染 → 校验），否则画面和声音会对不上。

## 规格

| 项 | 值 |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 24 fps |
| 视频 | H.264 High，CRF 21，yuv420p，**moov 前置（faststart，可拖进度条）** |
| 音频 | AAC 48 kHz 单声道，192 kb/s |
| 配音 | Edge TTS（zh-CN-YunxiNeural，语速 +6%），**逐场合成，时长以音频实测为准** |

| 画面 | HTML → 无头 Edge 截图，逐帧亚像素推镜（不是 `zoompan`） |

## 交付前跑了两轮自动校验

| 轮 | 检查 | 判据 |
|---|------|------|
| 一 | 时长对齐 | 视频 vs 旁白实测，偏差 ≤ 0.5s |
| 一 | 画面命中 | 每段中点抽帧，与全部段画面做最近邻比对，必须命中自己 |
| 一 | 抖动量化 | 段内连续抽帧：冻结帧 ≤ 5%、抖动残差 RMS ≤ 0.02 |
| 二 | 字幕帧轴 | 每行起止吸附到整数帧（ASS 厘秒精度上限 0.12 帧） |
| 二 | 字幕音频轴 | 每行落在所属场景的音频区间内 |
| 二 | 字幕时间轴 | 覆盖完整、无 2 秒以上空缺 |
| 二 | 视觉反证 | 有字幕时底部差异 ≫ 无字幕时刻，证明字幕真烧进去了 |

## 已知取舍

- **体积偏大**：逐帧亚像素渲染让每帧都不重复，x264 失去"重复帧"压缩红利。**体积小反而可能是抖动的症状**，别拿体积当质量指标。
- **场景顺序与旁白语义是近似的**：一屏铺满一个场景，旁白里的"先说 A 再说 B"没有做成逐步揭示。要逐步揭示得把每场拆成多个分步画面（`plan_timeline.py` 的 `weights` 已支持）。
- **字幕反证有时缺空档样本**：六条片子的字幕基本连续，个别片子的校验二会打一条 `[WARN] 没找到空档，无法反证`，此时退化为只比对"有字幕时的差异"。
- **配音是 Edge TTS 的中性男声**，没有做角色区分；六条片子听起来是同一个人在讲，这是有意的（同一套叙述者便于连播）。
- **没有背景音乐版权问题**：配乐是 numpy 算出来的，不是采样库。
- **画面只放标题和要点**，没有放架构图。架构图在 `overview.html` 里，**视频里没画**——要加图得改 `_slide_html` 模板重跑。
