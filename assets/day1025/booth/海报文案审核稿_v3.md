## 三、主标题 / 副标题候选

### 主标题

| 方案 | 文案 | 评价 |
|------|------|------|
| **A（推荐）** | 让每一辆公交的工艺<br>被内容放大成订单 | demo Hero 原句，有情绪、有品牌，适合展位远距离阅读 |
| B | AI 驱动的<br>客车内容营销平台 | 稳，但工业感、缺记忆点 |
| C | 从 12 条客户提问<br>长出一套能签字的内容 | 最"说事"，把方法论说出来，但略长 |

### 副标题

| 方案 | 文案 |
|------|------|
| **A（推荐）** | 以 12 条客户真实提问为唯一创意源，一次生成官网 / 公众号 / 销售推介 / 展会四件套，并自动找到对的人 |
| B | 每条结论挂引用编号与置信度，低置信度强制人工确认——说出去的每句话，都经得起追问 |
| C | 从行业提问到可授权的答案：内容有出处、口径有版本、边界说清楚 |

> 建议：**主标 A + 副标 A**（一感性一理性）；若评审更看重方法论，用 主标 C + 副标 B。

## 五、项目优势（为什么比"人肉做内容"强）

| # | 优势 | 具体表现 | 对应客户痛点 |
|---|------|---------|-------------|
| 1 | **口径唯一** | Schema 固定 → 因果识别 → Agent 预检 → 效果回流；口径卡统一版本 | 品牌团队"每次都要重新找资料、核实口径" |
| 2 | **边界自动守住** | 规则层拦截禁用词/阶段词，语义层给原因，人工签字放行 | REV01–REV05 反复踩坑、海外客户怕过度承诺 |
| 3 | **从找资料到出稿一步到位** | 7 大数据源 → 4,820 家企业 → 决策人识别 78.4% | 一线销售缺素材、缺画像 |
| 4 | **自下而上可校正** | 一线生成 → 负责人校正 → 回流训练（第 28 轮队列） | 客户明确要求"自下而上优化"（real_request） |

## 九、红线（必须遵守，来自 05 清单）

- 禁用词：`已量产` `大规模商业运营` `全系具备` `所有车型` `无人驾驶商业运营` `高阶智能系统` `运营成本下降30%` `降本30%`
- 阶段词五档不得混用：辅助驾驶 < 自动驾驶合作 < 试点/测试 < 量产 < 已投入运营
- 海外/展会素材不得写成"已交付/已运营"；交流 ≠ 订单
- 若引用真实数字（1987 台 / 市占 86.6% / 节油率 8%–12% / 进博会 206 台）须带来源与时间——**当前海报未使用任何真实数字，只用 demo 模拟数据**
