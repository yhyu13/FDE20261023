# 先把钱算清，再谈营销平台

> 一句话：客户要一份能执行、能核账的试点方案；现有原型还没有证明花钱能换来生意。

制作说明：全部金额为脱敏教学情景，不是客户账单、供应商报价或预测。Edge TTS 使用中文男声 zh-CN-YunjianNeural，语速 -5%，音高 -5Hz，取稳重低音的方向；“浑厚”属于主观听感，不承诺真人声线。旁白与字幕同源，不直接上传客户纪要、联系人或原始资料。

### 场景 1 · 客户先要一个能执行的试点
- **要点**：
  - 选一个市场，说明先找谁、凭什么买、先做什么
  - 一线出初稿，负责人改方案
  - 每个动作都有预算、责任人和验证方法

**旁白**：客户先要一份能执行的营销方案。选一个市场，讲清楚找谁、为什么会买、先做哪件事。一线销售出初稿，负责人校正。平台有多少菜单，暂时排在后面。

### 场景 2 · 界面有数字，账还没有
- **要点**：
  - 商机金额不等于收入，收入也不等于回款
  - 随机上涨的曲线不能证明营销有效
  - 真实花费、成交、回款：目前都未核实

**旁白**：现在的演示有商机和回复率，但没有账单和回款记录。商机不能当收入，收入也不能当到账的钱。代码里有些指标会随机上涨，这只能演示界面，不能拿来决定继续花钱。

### 场景 3 · 四本账，别混在一起
- **要点**：
  - 客户营销支出：付给媒体、达人、制作方
  - 软件收入：客户付的软件和服务费
  - 代收代付不是软件收入；交付成本另算

**旁白**：先分四本账。客户给媒体和达人的钱，是营销支出。客户付的软件服务费，才是软件方自己的收入。如果平台代付广告费，经手的钱不能全算收入。软件方还得扣掉实施、审核、模型和支持成本。

### 场景 4 · 假设花八万五，钱去了哪里
- **要点**：
  - 90天单市场教学情景，未获预算批准
  - 媒体3万；达人1.2万；制作0.8万；活动0.5万
  - 软件1.5万；直接数据0.3万；归属人工1.2万

**旁白**：下面只是假设，不能照着批准预算。一个九十天的试点，媒体三万，达人一万二，制作八千，活动五千。再加软件一万五，数据三千，归属人工一万二。合计八万五，其中假设外付七万三，人工是分摊成本。

### 场景 5 · 卖了三十万，仍可能没回本
- **要点**：
  - 假设3个新客户，每笔净收入10万
  - 履约后、营销前贡献率25%：贡献7.5万
  - 再扣营销8.5万：差1万；四笔才回本

**旁白**：假设成交三个新客户，每笔净收入十万，看起来卖了三十万。但扣掉履约变动成本，贡献率如果只有百分之二十五，就剩七万五。再扣八万五的营销投入，还差一万。同样条件下，至少四笔才回本。这里还假设成交全部由试点新增，现实必须验证。

### 场景 6 · 软件方收一万五，也不是赚一万五
- **要点**：
  - 软件方假设自有服务收入1.5万
  - 直接交付成本1.25万：主要是实施、审核、支持
  - 交付贡献2500元，尚未扣获客、研发和管理

**旁白**：软件方也要单独算。收一万五的服务费，假设直接交付成本一万二千五，交付贡献只有两千五。模型费可能只是其中一项，实施和人工审核同样要钱。这两千五还没有扣获客、研发和管理，不能叫净利润。

### 场景 7 · 产品先补一条能核账的链
- **要点**：
  - 预算项 → 合同 → 验收 → 实付
  - 内容与渠道 → 去重线索 → 成交 → 回款
  - 负责人定预算和停止线，系统保留依据与版本

**旁白**：下一版先补一条链。每笔预算接到合同、验收和实付，再通过活动编号接到线索、订单和回款。负责人决定预算上限和什么时候停止。没有这条链，多一张效果看板，也回答不了这钱该不该继续花。

### 场景 8 · Agent帮忙查证，不替人签字花钱
- **要点**：
  - Skill写清输入、输出、工具和拒绝条件
  - 算术走代码；修改事实后，旧审批失效
  - 内容人审、预算审批、付款授权分别处理

**旁白**：Agent可以整理证据、比较方案、改渠道文案。钱由确定性代码计算。涉及事实改动，旧审批要失效。内容审过，不代表预算批了，更不代表付款获准。给Agent起几个岗位名字，不等于它有了可靠的工作方法。

### 场景 9 · 下一步先拿到账，再谈省多少
- **要点**：
  - 核清营销对象与单一市场，找当地销售负责人
  - 拿历史账单、活动记录、成交与回款数据
  - 当前金额全是教学假设；不是客户预算或成效

**旁白**：下一步先确认卖什么、试哪个市场、谁负责。再拿历史账单、成交和回款数据，分清哪些旧支出真能取消。今天这些金额都只是教学假设，不是客户预算，更不是已经赚到的钱。本讲解只用于研究参考。
