# 05 · 对外事实红线与陷阱清单（申沃智能驾驶内容）

> 用途：题 02 L2-3「合规红线双层校验」的**可执行清单**。机器跑规则层，人跑语义层。
> 每条红线都标注：**触发条件 / 判定 / 放行条件**。**没有放行条件的 = 一律阻断。**
> 依据：REV01–REV05、APPROVAL-01（P01–P03）、S01–S11 使用边界、PIC01–05 配图边界、二轮外部检索（2026-10-25）。

---

## 一、阶段词红线（最高优先级，REV01/REV03 就栽在这里）

五档必须严格区分：**辅助驾驶 < 自动驾驶合作 < 试点/测试 < 量产 < 已投入运营**

| # | 触发条件（正则/关键词） | 判定 | 放行条件 |
|---|----------------------|------|---------|
| R-01 | 出现 `RoboBus` 且同句/同段出现 `量产`/`大规模商业运营`/`已投入运营` | **阻断** | 无。**目前零证据支持。** 只能写"合作方向涉及 RoboBus"（S11 / 中新网上海 2026-06-06） |
| R-02 | 出现 `所有车型`/`全系` + `无人驾驶`/`自动驾驶`/`相同.*能力` | **阻断** | 无。不同车型配置不可泛化（REV03） |
| R-03 | 出现 `高阶智能系统` 等模糊智能表述而未注明档位 | **阻断** | 改写为具体档位 + 出处（辅助驾驶，S06 奉浦快线交付车辆） |
| R-04 | 出现 `试点`/`已试点`/`在某城试点` + 具体城市名 | **阻断** | 官方仅"共同推进商业化**试点与市场推广**"，**试点城市与时间未公布**（中新网上海 2026-06-06） |
| R-05 | 出现 `来访`/`交流`/`考察` 且同段出现 `订单`/`签约`/`落地`/`部署` | **阻断** | 无。交流 ≠ 订单（REV04 / S09） |
| R-06 | 出现 `展会`/`亮相`/`首发`/`发布` 且同段出现 `交付`/`投运`/`已运营` | **阻断** | 无。展会 ≠ 交付（S05 / S10 使用边界） |
| R-07 | `辅助驾驶`/`驾驶辅助` 与 `自动驾驶`/`无人驾驶` 在同一段落混用而未显式区分 | **阻断** | 分开成两段，各自带出处 |

**禁用词表（机器直接拦）**：
`已量产` `大规模商业运营` `全系具备` `所有车型` `无人驾驶商业运营` `高阶智能系统` `运营成本下降30%` `降本30%`
**强制成对词（出现前者必须同时出现后者）**：
`RoboBus` → 必须同现 `合作方向` 或 `战略合作`
`驾驶辅助` → 必须同现具体车型/项目（如"奉浦快线 BRT 交付车辆"）
`智能网联` → 必须同现出处编号

## 七、校验流水线（双层）

```
规则层（机器，毫秒级）
  1. 禁用词表命中 → 阻断 + 报出命中词与位置
  2. 强制成对词缺失 → 阻断
  3. R-01..R-07 / S-01..S-05 / P-01..P-03 正则命中 → 阻断
  4. {{fact_id}} 未替换 / 与口径卡不一致 → 阻断
  5. 来源编号缺失或等级 4 → 阻断
        ↓ 全部通过
语义层（LLM）→ 输出拦截原因（不是只给"不通过"）
        ↓
人工签字（不可省）→ 放行
```

**护栏要求**：拦截必须给出**原因与出处**（题 02 原 L3）；KR4 要求对抗测试 10 条错误样本 **拦截率 100%**，不接受"大部分拦住"。

## 八、本清单的已知盲区

1. **禁用词表不完整**——只覆盖了 REV01–05 与二轮检索碰到的情况，Day1 需市场部补正式清单。
2. **`运营成本` 这类话题目前无可用数字**，一旦市场部给出测算材料，N-01 需要撤销并换成新 fact_id。
3. **等级 4 来源的识别靠人工**，机器无法可靠判断媒体等级，需维护一份来源域名白/黑名单。
4. 本清单**未覆盖英文/海外物料**（澳洲、美洲、欧洲市场的表述边界另有一套，未调研）。
